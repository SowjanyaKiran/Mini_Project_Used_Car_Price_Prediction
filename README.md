# Mini_Project_Used_Car_Price_Prediction

This is a **Streamlit** web application for predicting the selling price of used cars using a pre-trained **CatBoost** model. Users can enter car details such as year, kilometers driven, fuel type, dealer type, transmission, and ownership to get an estimated price.


## Features

- Predicts used car prices based on user input
- Supports multiple fuel types: Petrol, Diesel, CNG, Electric, LPG
- Handles different dealer types: Dealer, Individual, Trustmark Dealer
- Supports both Manual and Automatic transmission
- Accounts for the number of previous owners
- Simple and interactive **Streamlit sidebar** interface



## Tech Stack

- Python 3.x
- Streamlit
- Pandas
- NumPy
- scikit-learn
- CatBoost
